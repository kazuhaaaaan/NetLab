# NetLab Architecture Overview

## Clean Architecture Layers
1. **Presentation Layer**: `@mikrolab/ui`, `@mikrolab/canvas`, `@mikrolab/terminal`
2. **Translation Layer**: `@mikrolab/vendors`, `@mikrolab/cli`
3. **Domain Layer**: `@mikrolab/core`, `@mikrolab/devices`
4. **Networking Engine Layer**: `@mikrolab/packet`, `@mikrolab/protocols`
5. **Infrastructure & SDK**: `@mikrolab/shared`, `@mikrolab/sdk`
